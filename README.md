# PACMAN 🟡

Juego de Pac-Man desarrollado en **C#**.

## Autora

Samantha Tobón

## Descripción

Este proyecto es una versión del clásico juego Pac-Man programada en C#.
Fue desarrollado como proyecto académico.

## Requisitos

- Visual Studio 2022 (o superior) con la carga de trabajo de .NET
- .NET Framework (según la versión indicada en `App.config`)

## Cómo ejecutar

1. Clona el repositorio:

```bash
   git clone https://github.com/samanthatobon-233/PACMAN.git
```

2. Abre el archivo `PACMAN.sln` con Visual Studio.
3. Presiona **F5** o el botón **Iniciar** para ejecutar el juego.

## Estructura del proyecto

- `Program.cs`: punto de entrada y lógica principal del juego
- `Fantasma.cs`: clase que representa a los fantasmas
- `PACMAN.sln` / `PACMAN.csproj`: archivos de la solución y el proyecto
- `App.config`: configuración de la aplicación
